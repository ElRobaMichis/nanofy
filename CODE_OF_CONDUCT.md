# Code of conduct

Nanofy is a small project made in someone's free time. To keep it a pleasant place to contribute:

- Be kind and assume good intent. Everyone was a beginner once.
- Critique code and ideas, never people.
- Write in English or Spanish; both are welcome, and nobody should be made to feel bad about their language.
- No harassment, insults, discrimination or sexual content, in issues, pull requests or anywhere else related to the project.

The maintainer can edit or delete comments, close discussions and block people who don't follow this.
If someone makes you uncomfortable, report it privately through
[GitHub's security advisories](https://github.com/ElRobaMichis/nanofy/security/advisories/new) or by contacting the maintainer on GitHub.
